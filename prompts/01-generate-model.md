# Промт 01 — генерація моделі

Ти — аналітик даних. На основі файлу `spec.md` (додається) побудуй ER-модель у Mermaid `erDiagram`.

Вимоги:
- Лише синтаксис Mermaid, без SQL DDL та ORM.
- Сутності й назви полів — рівно як у spec.md.
- Атрибути позначай PK / FK / UK; усі id — тип int.
- Кардинальності — за таблицею зв'язків (розділ 2).
- Чисті M:N — прямий зв'язок `}o--o{`, без сполучних сутностей. Асоціативна сутність — лише LOAN.
- Перевір усі критерії AC-1…AC-10 і окремо виведи список порушень, якщо вони є.

Вихід: один блок коду `model.mmd`, потім список порушень (або «порушень немає»).
